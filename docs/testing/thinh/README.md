## Mục đích

Tài liệu này được lập nhằm thực hiện Review giao diện Website FutureSuShi theo phương pháp Formal Technical Review (FTR).

Quá trình review giúp phát hiện các lỗi về giao diện, đánh giá trải nghiệm người dùng và đề xuất các hướng cải thiện trước khi chuyển sang giai đoạn kiểm thử tiếp theo.
